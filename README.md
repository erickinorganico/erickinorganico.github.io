# Erick Peralta - Portafolio

Sitio personal en español sobre Growth & Product Analytics, datos y automatización con IA.

**Web:** https://erickinorganico.github.io  
**Contacto:** https://www.linkedin.com/in/erickperalta5813/

## Editar

- `index.html`: textos, enlaces, capacidades y casos.
- `styles.css`: colores, tipografía, diseño adaptable y animaciones.
- `script.js`: comportamiento de los casos y mejoras de navegación.
- `assets/erick-peralta-perfil.pdf`: presentación descargable. Reemplazar cuando cambie el contenido.
- `assets/social.png`: imagen de vista previa para compartir el enlace.

No requiere instalar dependencias ni ejecutar un build. Para una vista previa local se puede usar `python -m http.server 8000` desde esta carpeta y abrir `http://localhost:8000`.

GitHub Pages publica la rama `main`, carpeta raíz. Después de guardar cambios en GitHub, comprobar el despliegue de Pages antes de compartirlos.

## Contenido

Casos profesionales resumidos y adaptados para presentación pública. Las contribuciones se describen dentro de trabajo colaborativo; no incluyen información comercial o datos internos. El diagrama de portada es conceptual y no representa métricas reales.

El sitio no incorpora rastreadores, formularios que recopilen datos ni servicios externos de fuentes. LinkedIn y GitHub son enlaces externos. Se respeta la preferencia de movimiento reducido del dispositivo.
