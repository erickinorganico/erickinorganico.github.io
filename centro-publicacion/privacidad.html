Quién opera la aplicación

Centro local de publicación es una herramienta local de uso privado operada por Erick Peralta (Pensamientos Inorgánicos). Está diseñada para operar canales del propio operador desde su equipo Windows; no se ofrece como servicio público ni se registran usuarios externos.

Contacto para consultas de privacidad: pensamientosinorganicos@gmail.com.

Datos de Google y YouTube que se usan

Cuando el operador conecta YouTube, la aplicación solicita los permisos youtube.upload y youtube.readonly. Para dar las funciones solicitadas, puede procesar:

  • Datos de autorización OAuth, incluidos tokens de acceso y renovación.
  • Identificador y nombre del canal autorizado, para comprobar que corresponde al destino elegido.
  • El video seleccionado, sus metadatos y controles de publicación o programación que el operador aprobó.
  • El identificador, enlace y estado que devuelve YouTube para verificar esa operación.

La aplicación usa estos datos sólo para conectar y comprobar el canal, cargar el video que se eligió y revisar su resultado. No los vende ni los usa para publicidad, perfilado o vigilancia. La aplicación no incorpora ni consulta modelos de inteligencia artificial y no utiliza estos datos para entrenarlos. No comparte datos de YouTube con otros destinatarios; la transmisión a Google y YouTube es necesaria para las funciones solicitadas.

El uso y la transferencia de información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de Limited Use.

Envíos de red

Durante la autorización, el navegador abre la página de consentimiento de Google. La aplicación intercambia el código y renueva los tokens con los endpoints oficiales de Google; las solicitudes de YouTube se envían a YouTube Data API. El video y los metadatos salen del equipo cuando el centro ejecuta la operación de carga o programación autorizada. Si se fija una fecha futura, YouTube recibe la solicitud y administra la publicación posterior conforme a sus propias funciones. El sitio informativo de esta página no recibe videos, tokens, copys, identificadores de canal ni calendarios.

El centro también tiene conexiones independientes para otras plataformas. En una operación dirigida a ellas, los materiales correspondientes se envían a la plataforma seleccionada; los detalles de acceso a datos de Google descritos aquí se limitan a la conexión Google/YouTube.

Almacenamiento y conservación

Los tokens de Google se cifran con Windows DPAPI y quedan en almacenamiento local asociado al usuario de Windows que autorizó la cuenta, fuera de OneDrive. Los medios, copys, fechas, identificadores, enlaces y recibos operativos se conservan localmente en los expedientes del operador. La aplicación no los sube a este sitio ni los elimina automáticamente.

La conexión local se conserva hasta que el operador la desconecta o la credencial deja de ser válida. Los archivos y recibos locales se administran manualmente en su almacenamiento. Google puede conservar información que ya recibió y YouTube conserva los videos o programaciones aceptados conforme a sus propios términos y controles.

Revocación y eliminación

El operador puede revocar el acceso de la aplicación desde los permisos de su cuenta de Google y quitar manualmente la credencial local del centro. Revocar o quitar esa credencial detiene el acceso futuro del centro; no borra publicaciones ni cancela programaciones que ya existan en YouTube. Esos elementos se administran desde YouTube Studio.

Visita de estas páginas

Estas páginas son HTML estático: no cargan scripts, analítica, formularios, píxeles ni contenido incrustado, y no establecen cookies propias. GitHub Pages aloja el sitio. GitHub informa que registra la dirección IP de quien visita un sitio Pages por motivos de seguridad; ese tratamiento se rige por la documentación de GitHub Pages y la declaración de privacidad de GitHub.
