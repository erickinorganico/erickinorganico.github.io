Información de la aplicación

Centro local de publicación

Es una herramienta local de uso privado para preparar y operar publicaciones en canales controlados por su operador. No es un servicio disponible al público ni una plataforma de registro para terceros.

La conexión de Google se usa con YouTube Data API para identificar el canal autorizado, enviar videos y metadatos cuando el operador ejecuta una operación aprobada, y comprobar el resultado. La aplicación solicita únicamente estos permisos de YouTube:

  • youtube.upload: cargar los videos elegidos por el operador.
  • youtube.readonly: comprobar la identidad del canal y leer los datos de estado necesarios para verificar una carga o programación.

El centro conserva los archivos, textos, fechas, identificadores, enlaces y recibos de trabajo en el entorno local del operador. El token de Google se cifra con Windows DPAPI para el usuario de Windows que autorizó la conexión. Al cargar o programar en YouTube, el centro transmite sólo los datos necesarios para la operación que el operador autorizó; si se fija una fecha futura, YouTube recibe esa solicitud y controla la publicación posterior. La aplicación no vende esos datos ni los usa para publicidad: no incorpora ni consulta modelos de IA, y no incorpora analítica o telemetría propia.

El centro incluye conexiones separadas para otras plataformas. Este sitio describe el flujo de datos de Google/YouTube; cada plataforma recibe únicamente los materiales de las operaciones que el operador dirige a ella.
